# Nassau Candy Distributor – Profitability Analysis Dashboard

## 📊 Project Overview
This project analyzes product profitability and margin performance for Nassau Candy Distributor. The dashboard helps identify profitable product lines, margin risks, division performance, and key business insights.

## 🚀 Live Dashboard
👉 ([https://w8aupul5uvhbdxhavnbj4f.streamlit.app/])

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## 📌 Key Analysis
- Sales, Cost & Gross Profit Analysis
- Gross Margin Analysis
- Product & Division Performance
- Margin Risk Identification
- Profit Contribution Analysis
- Interactive Filters and Visualizations
